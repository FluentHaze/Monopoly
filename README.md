# 大富翁游戏

一个基于Vue 3和TypeScript开发的大富翁游戏，具有精美的UI设计和流畅的动画效果。

## 项目介绍

这是一个网页版的大富翁游戏，玩家通过掷骰子在游戏棋盘上移动，收集奖励并完成各种任务。游戏具有精美的视觉效果、流畅的动画和直观的用户界面。

## 技术栈

- **框架**: Vue 3.5.17
- **语言**: TypeScript
- **构建工具**: Vite
- **路由**: Vue Router 4.5.1
- **状态管理**: Pinia 3.0.4
- **UI组件**: Vant 4.9.21
- **动画**: Spine动画库
- **样式**: SCSS

## 功能特性

- **游戏棋盘**: 精美的大富翁游戏棋盘，包含37个不同类型的格子
- **掷骰子**: 使用Spine动画实现逼真的掷骰子效果
- **角色移动**: 流畅的角色移动动画，支持前进、后退和传送
- **奖励系统**: 丰富的奖励系统，玩家可收集各种奖励
- **任务系统**: 完成任务获取额外奖励
- **回合奖励**: 每完成一定回合数可获得特殊奖励
- **倒计时系统**: 游戏活动倒计时显示

## 游戏规则

1. 玩家通过点击"掷骰子"按钮开始游戏
2. 根据骰子点数在棋盘上移动相应格数
3. 到达不同类型的格子会触发不同效果
4. 收集奖励并完成任务
5. 完成指定回合数可获得特殊奖励

## 游戏组件说明

### Map.vue
游戏地图组件，负责渲染游戏棋盘和处理玩家移动逻辑。

### Box.vue
游戏格子组件，显示不同类型的格子和奖励。

### TurnsReward.vue
回合奖励组件，显示玩家在完成特定回合数后可获得的奖励。

### Time.vue
倒计时组件，显示游戏活动剩余时间。

### Task.vue
任务组件，显示玩家需要完成的任务。

## 动画效果

游戏使用Spine动画库实现流畅的动画效果，包括：
- 骰子投掷动画
- 角色移动动画
- 传送动画
- 格子激活效果

## 响应式设计

游戏使用postcss-pxtorem插件实现响应式设计，自动将px转换为rem单位，适配不同屏幕尺寸。
