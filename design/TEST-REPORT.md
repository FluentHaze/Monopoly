## PC/H5 实际完整流程

两个尺寸分别从全新状态运行同一组 16 次投掷，未跳过中间动画：

- 原始点数：`5, 3, 6, 4, 3, 1, 6, 6, 5, 6, 1, 1, 6, 6, 6, 1`。
- 每回合最终位置（内部 ID，0 起算）：`9, 8, 14, 18, 21, 22, 23, 22, 27, 35, 36, 11, 17, 23, 29, 0`。
- 覆盖：5→9 传送、12→8 后退、额外骰子、慢行三次、后退后的新落点、27→30 特殊分支、36→11 返回外围、29→0 跨圈。
- 结果：完成 1 圈，剩余 87 次骰子，获得 150 金币；领取第 1 圈宝箱后 200 金币。
- 刷新后位置、圈数、骰子、金币与已领取记录保持一致，已领取按钮不可重复点击。

## 动画与边界

- 点数 1–6 的可见骰子点数、最终位置和扣减次数一致。
- 慢行时显示点数 1，步数 1，消耗 1 次骰子。
- 原 Spine 动画正常加载；禁用 WebGL 后 CSS 投掷动画仍可完成回合。
- 角色有逐格移动、跳跃、朝向、传送消失和出现；动画中改变 PC/H5 尺寸，角色仍落在正确格子。
- 重复点击不会增加投掷次数，整回合只扣一个骰子。
- 无骰子、活动到期、无效点数、无效传送目标、道具循环均有边界处理。
- 后退到起点即停，后退不倒扣圈数；传送到起点不计圈数；经过分支入口不直接转入内圈。
- 检查了格子详情、玩法弹窗、键盘关闭/焦点循环、取消重置与确认重置。
